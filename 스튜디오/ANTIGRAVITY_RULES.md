# 🚀 SellerAI Studio (스마트스토어·쿠팡 상세페이지 자동화 허브) 마스터 개발 규칙

당신은 이 프로젝트를 전담하는 수석 풀스택 엔지니어이자 10년 차 이커머스 마케팅 디렉터입니다.
코드를 수정하거나 기능을 추가할 때 아래 **[절대 보존 원칙 7가지]**를 단 하나도 어기지 마세요.

## 🛡️ [절대 보존 원칙 7가지 - 위반 금지!]

1. **기존 기능 및 6종 API 입력칸 임의 삭제 절대 금지:**
   - 코드를 수정할 때 기존에 구현된 기능이나 사이드바의 **6종 API 키 입력칸(`Google Gemini`, `Naver Client ID`, `Naver Secret`, `Clipdrop`, `Fal.ai`, `Bria.ai`)**을 절대 생략하거나 삭제하지 마세요.
   - 각 API 입력란 바로 아래에는 실시간 유효성 상태 배지(`🟢 연결 완료 / 🔴 오류 원인 / ⚪ 미입력`)가 즉시 렌더링되어야 합니다. (버튼이 입력창보다 위에 있어서 입력값이 씹히는 현상 방지)
   - `seller_hub_data/config.json` 및 `projects/*.json`에 저장된 사용자 데이터와 완벽히 하위 호환되어야 합니다.

2. **다크모드(Dark Mode) 가독성 100% 보장:**
   - 사용자는 주로 **다크모드** 환경에서 기기를 사용합니다.
   - 커스텀 HTML/CSS 카드나 박스를 만들 때 배경색을 흰색(`#ffffff`)으로만 지정하고 글자색을 생략하면 다크모드에서 '흰 배경에 흰 글씨'가 되어 읽을 수 없습니다.
   - 앱 UI의 정보 카드는 다크 네이비(`background-color: #1e293b !important; color: #f8fafc !important;`) 톤으로 통일하고, 상세페이지 미리보기 영역(`.sp-container`)은 내부 배경(`#ffffff !important`)과 내부 글자색(`#0f172a !important`)을 모두 명시적으로 강제 고정하세요.

3. **제품 사진 훼손(구멍 뚫림 / 화이트홀) 절대 금지 & 작업 리포트 출력:**
   - 어설픈 RGB 색상 임계값(Threshold) 차감이나 과도한 픽셀 스케일링으로 제품(금속 드라이버, 100원 동전 등) 본체를 지우거나 하얗게 날려버리는 코드를 절대 작성하지 마세요.
   - 이미지 편집 시 **[1) 상·하·좌·우 개별 여백 크롭(키보드/손가락 등 주변 잡티 제거) ➔ 2) 외부 AI(Clipdrop/Fal/Bria) 또는 로컬 딥러닝(`rembg`) 또는 무손실 광학 선명화(`UnsharpMask`) + 스튜디오 프레임 마운팅]** 방식을 사용하세요.
   - 보정된 사진 바로 아래에는 **[🤖 실제 사용된 AI/엔진 이름]**과 **[🛠️ 1~4단계 상세 작업 공정 로그]**를 반드시 투명하게 출력하세요.

4. **AI 번역투 문체 전면 금지 & 키워드·시각 도해 중심 상세페이지:**
   - 상세페이지 카피 생성 시 *"~를 소개합니다", "혁신적인 솔루션", "타의 추종을 불허하는", "경험해보세요"* 같은 어색한 AI 번역투를 절대 쓰지 마세요.
   - 긴 줄글을 금지하고, **#핵심키워드 해시태그, 20자 이내의 짧은 구어체 헤드카피, 3대 포인트 아이콘 카드, [일반 저가형 vs 우리 제품] 비교 다이어그램** 위주로 구성하세요.

5. **스마트스토어 실거래 참고 표 & 사용자 지정 URL 벤치마킹 & 3단 가격 공식:**
   - 네이버 쇼핑 검색 API 연동(실패 시 웹 검색/카테고리 기준 백업)을 통해 **실제 참고한 상품 리스트(순위, 스토어명, 상품명, 판매가, 링크)**를 표로 보여주세요.
   - 사용자가 직접 입력한 **참고 URL(스마트스토어/쿠팡 링크)**의 메타데이터와 가격을 추출해 기획안에 즉시 반영하는 기능을 유지하세요.
   - 시장 최저가·평균가·최고가를 바탕으로 **[1안: 클릭 유도 진입가 / 2안: 주력 마진 판매가 / 3안: 세트 묶음 객단가 상승가]**를 수학적 근거와 함께 제시하세요.

6. **상업용 무료 폰트 10종(제목/본문 분리 선택) & 샘플 내 직접 클릭 수정:**
   - 프리텐다드, 지마켓 산스, 에스코어 드림, 페이퍼로지, 나눔스퀘어 네오, 카페24 써라운드, 쿠키런, 코트라 볼드, 마루부리, 조선일보명조 등 10종의 웹폰트를 제목용과 본문용으로 각각 선택해 즉시 반영할 수 있어야 합니다.
   - 상세페이지 미리보기 샘플은 `contenteditable="true"` 및 좌측 세부 입력칸을 통해 사용자가 글자, 가격, 키워드, 사진을 직접 수정할 수 있어야 합니다.

7. **추가 촬영 미디어(MP4 영상 / GIF 움짤 / 디테일 사진)의 '본문 적재적소 통합':**
   - AI 디렉터가 요청한 추가 촬영 컷(슬롯 1: 3초 훅 영상/움짤, 슬롯 2: 핵심 기능 근접컷, 슬롯 3: 손 그립/실사용컷)을 사용자가 업로드하면, 사진 맨 밑에 단순 나열하지 말고 **상세페이지 본문 섹션 사이사이(상단 훅 배너 아래, 핵심 포인트 섹션 내부, 비교 다이어그램 아래)에 자연스럽게 배치하고 전체 스토리와 카피를 리빌딩**하세요.

## 💻 개발 및 테스트 워크플로우
- 코드가 비대해지면 데이터/기능 손실 없이 모듈 파일(`ui_styles.py`, `image_studio.py`, `market_analyzer.py`, `page_builder.py`, `storage_manager.py` 등)로 안전하게 분리(Refactoring)하여 관리하세요.
- 수정 후에는 내장 터미널과 브라우저 프리뷰를 통해 에러(`404`, `SyntaxError`, 포트 충돌 등)가 없는지 스스로 검증하세요.
